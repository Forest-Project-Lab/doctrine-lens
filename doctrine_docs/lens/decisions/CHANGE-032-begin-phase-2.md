# Phase 2 の実装を始める — 基準線と裁定の記録

## 何が起きているか

所有者が Lens 側 Phase 2 の実装開始を裁定した(ADR-031。裁定の文面は自身を 2026-08-10 と日付ける)。上流は #212 第3信で
上流から lens 側へ求めるものは無いと述べ、五件を lens の領分として置いている。

動いている対象を古い写しのまま測らないため、開始時点を実測して固定した。

| | 開始時点(2026-08-09 21:23 UTC 取得) |
|---|---|
| Lens `main` | `9124370`(v0.10.0)。open PR 0 件・open Issue #12 のみ |
| Lens の CI | `check`・`system-map verify` とも成功 |
| Doctrine `main` | `773198b` |

| **導入済みの Doctrine(手元)** | **0.10.0**。`map-draft-check.py` も `system-map-draft` 技能も無い(0.11.0 で入った) |

## 変更内容

本文書と同じ変更で実施するのは、記録と基準線だけである。実装は主題ごとに別の変更で行う。

- `ADR-031`(新規)— 裁定の範囲・含まれないもの・M 層の裁き・判定語彙・固定の方針。
- `IMPACT-032`(新規)— 波及の見積。
- `research/system-map/decisions/phase-2-baseline/`(新規)— 開始時点の全門の生ログと件数。
  終了コードだけでなく、検査件数・PASS/FAIL/SKIP・対象 SHA を残す。
- 実測した空判定の一覧(10 件)を同じ場所へ置く。これが以後の作業の RED の起点である。

続く主題(別の変更で行う。順序は依存で決まる):

1. Issue #12 の再測定と処遇の確定
2. M 層の正本の単一化と三門の整合(判定語彙・負例・門が発火しなくなる変異の検出)
3. Doctrine 実体・版・SHA の解決
4. 対象とパスの一般化と、成果物の byte 一致
5. 複数対象の overlay と配線
6. 画面
7. 環境と異常系の試験
8. E2E(2対象)・配布物・判定の材料
