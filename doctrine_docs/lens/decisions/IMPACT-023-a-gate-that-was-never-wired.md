## 工数見積

**事後に立てた見積は置かない**（`ADR-017`）。この変更は上流 v0.10.0 を
取り込んだ直後の一巡で見つけ、同じ巡で直した。実際に動いた量は
この PR の差分が示す。

## 順序の不変条件

**門を先に結び、赤いまま直す。** 逆にすると「いま何が残っているか」が
読めない。実測でも、241→221→203→169→147→139→124→90→5→0 と
段ごとに数が減るのを見ながら判じられた。

**辞書を直す前に、真の違反を先に直す。** 逆にすると、辞書を緩めた分だけ
違反が消え、「どれが本当の違反だったか」が永久に分からなくなる。

**外す語は、別の意味の実在を数で示してから外す。**
「読みにくいから」では外さない。上の表の件数がその根拠である。
