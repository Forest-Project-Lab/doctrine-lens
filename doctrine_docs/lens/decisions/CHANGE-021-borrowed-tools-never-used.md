# 借りてきた道具 1445 行が、一度も使われていない

## 何が起きているか

`tools/doc-manager/` に **1445 行**（7 ファイル）が在る。

```console
$ wc -l tools/doc-manager/*.mjs
 1445 total
$ ls -d docs                       # 入力の在処
無い
$ git log --all --diff-filter=A -- 'docs/*'
（一件も無い）
$ npm run docs:aggregate
No docs/targets/ directory yet — create one and add <name>.json batch files.
```

**入力のディレクトリ `docs/` は、この木の歴史で一度も存在したことがない。**

`package.json` は四つの命令を持つ（`docs:aggregate`・`docs:fetch`・`docs:extract`・`docs:diff`）。
どれも走らせると「まだ無い」と言って終わる。

## 何が問題か

`.context-config.json` は理由付きで除外している。

```json
"tools/doc-manager/": "claude-harness キットから持ち込んだ道具。lens ドメインの実装ではない"
```

**除外は正しい。** これは lens の実装ではない。**問題は、除外したまま残っていることである。**

| | 実測 |
|---|---|
| 行数 | **1445** |
| 試験 | **0** |
| CI | **走らない** |
| 配布物（`.vsix`）に入るか | **入らない** |
| 入力 `docs/` | **一度も存在しない** |
| 最後に触った日 | **2026-07-28**（この木の最初の日） |

**使われていないものが、読む人の目に入り続ける。**
`IMPL-001` は部品の表を持つが、この 7 ファイルは載っていない——
**載せる場所が無いものが、木の中に在る。**

## `CHANGE-018` と同じ形か、違うか

`CHANGE-018`（写しの残骸）と `CHANGE-017`（`ICD` の名乗り）は
「**捨てたのに残った**」だった。これは「**使う気で持ってきたが、一度も使わなかった**」である。

同じではない。だが行き着く先は同じ——**読む人が「これは何だ」と問う。**

## 変更内容

1. **消す。** `tools/doc-manager/` の 7 ファイルと、`package.json` の四つの命令
   （`docs:aggregate`・`docs:fetch`・`docs:extract`・`docs:diff`・`docs:refresh`）。
2. `.context-config.json` の `trace_exempt` から一行落とす。
3. `SPEC-007` が「潰しの表が覆わない範囲」として名指している箇所を直す。
4. **消したことを記録に残す。** 次に同じ道具が要ると思った人が、
   **なぜ消えたかを辿れる**ようにする（`CHANGELOG` と この文書）。

## 却下する見込みのもの

- **残して「いつか使う」と書く。** `NONGOAL-001` は
  「**まだ作っていないものはここに書かない。ここに在るのは作らないと決めたもの**」と定める。
  **「いつか使う」を木に書く場所は無い。**
- **試験と CI を足して生かす。** 入力が一度も存在しない道具に門を足すのは、
  **使われない仕掛けに投資すること**である。要るときに要るものを取り直すほうが安い。

## 見えている難所

**取り戻せることを確かめる。** git の履歴に残るので戻せる。
要るときはここから取る。

```console
$ git checkout 40dd24fbbe0475f2e1ea7a8f86059ee76542b9d0 -- tools/doc-manager/
```

**消す前に、どのコミットから取れるかを書いた。** 書かないと、
次に要ると思った人が履歴を掘ることになる。

### 直さなかったもの — 「34 検査」

`ADR-012`・`ADR-014`・`CHANGE-004`・`CHANGE-005`・`CHANGE-007`・`IMPACT-004`・`IMPACT-005` が
「34 検査」と書いており、いまの実測は **37** である。**直さない。**

測ったら、**実装にも門にも辞書にも「34」は一つも無い。**
すべて `ADR`／`CHANGE`／`IMPACT` の中——**当時の実測の記録**である。

`ADR-014` は「数を代弁する語を数量の位置に置かない」と決め、
`ADR-021` 決定 5 は「測った数には刻印を添える」と決めた。
**記録に残った当時の数は、刻印そのものである。** 書き換えると、
「そのとき何が見えていたか」が読めなくなる。

画面が出す数は `checks_run` の長さであり、実装は数を持たない——そこは既に守られている。
