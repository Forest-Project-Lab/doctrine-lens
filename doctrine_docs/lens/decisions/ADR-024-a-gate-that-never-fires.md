# 発火していない門を、緑と呼ばない

## 背景

`ADR-017` は「自分の門が緑であることを正しさの証拠にしない」と決めた。
その決定に従って独立の走査をかけたところ、**門そのものが発火していない箇所**が挙がった。

四つ見つかり、三つは `CHANGE-010` の中で塞いだ。残りをここで塞ぐ。

| 場所 | 何が起きていたか |
|---|---|
| `shoot-preview.mjs` `statusAgrees` | 既定の起点では両方 0 なので毎回 `0 === 0`。**行の `status` 欄を丸ごと消しても緑** |
| `mutate-check.mjs` の表を読む門 | `from: (.+)` が改行を跨がず、**55 行のうち 2 行を黙って読み飛ばす** |
| `bridge.test.ts` `006-26` | 注釈を落とさず数えるので、**この試験自身の注釈**で通る |
| `shoot-preview.mjs` `07-notice` | 期待が否定だけ。**通知の描画を殺しても通る** |
| `paths.test.ts` symlink | 主張が `if (found !== null)` の中だけ。**本体が一度も走らない** |
| `cadence.test.ts` 見本 | `staleIds.size >= 0` は**常に真**。片方の場合しか作らない |

**六つとも、落ちないので誰も気づかなかった。**

## 決定

### 1. 不変条件を試せない状態を、失敗として扱う

門が「今回は試せなかった」ことを、**門自身が言う。**

```
非現行の行が一つも出ない起点で撮ったので、この門は不変条件を一度も試していない
```

黙って通すと、**緑と「試していない」が見分けられない。**
`0 === 0` で自動的に一致する形は、一致ではない。

### 2. 否定だけを検めない。**出たことを主張する**

「溢れていない」「差し込みの跡が無い」は、**何も描かなくても真である。**
段ごとに「その操作が効いたか」を一つ以上主張する。

`07-notice` は、通知が**出たこと**（文が字面で残っていること）と、
空の通知で**消えること**の両方を検める形にした。

### 3. 零件の主張で通さない

`if (…) { assert(…) }` の形は、条件が偽なら**一度も走らない。**
条件が偽になりうるなら、**偽のときに何を期待するかも書く。**

```ts
if (found === null) {
  assert.equal(found, null);   // 繋ぎの先が外なので、統治木として認めない
  return;
}
assert.ok(…);
```

### 4. 常に真の条件を、見本に書かない

`staleIds.size >= 0` は `Set.size` が負にならないので常に真である。
**両方の場合を踏んでいるように読めて、片方しか作らない。**

### 5. 門を作るときに、門が嘘をつくことがある

「主張を一つも持たない試験」を探す門を、最初は**括弧の数で本体を切って**書いた。
正規表現リテラル `/[{;]/` の `{` に騙されて、**主張を持つ試験を三本「持たない」と報せた。**

門の言い分も測る。行頭の `test(` で区切る形へ直したら 0 件になった。

**新しい門の最初の判定は、疑ってから信じる。**

## 却下した選択肢

### 却下 1 — 発火していない門を「情報」として刷り、失敗にしない

落とさずに報せれば気づける。却下した。

**報せは読まれない。** `CHANGE-010` で実測した——潰しの門の頭注には
「未コミットは検査対象に入らない」と書いてあったのに、20 分読まれなかった。
**落とすことだけが読まれる。**

### 却下 2 — 「試せない起点」を門の側で作る（見本を注入する）

写しの門に、非現行を持つ偽の木を渡せば必ず発火する。却下した。

**写しの門の値打ちは、実物の木・実物の画面で撮ることに在る。**
見本を注入すると、実物では起きないことを検めることになる。
起点の選び方を直すほうが、実物の性質を保てる。

### 却下 3 — 零件の主張を、機械が全部見つける

「条件の中だけに主張が在る」を字面で探せば網羅できる。却下した（今回は）。

**擬陽性が支配する。** `if (!x) return;` のあとの主張は正当である。
いま門にできたのは「主張を一つも持たない試験」だけで、
これは字面で確実に判じられる。**判じられる範囲だけを門にする。**

## 帰結

- 写しの門が、通知の「出た」「消えた」を両方検める（段が一つ増えた）。
- 「主張を一つも持たない試験」が門になった。
- 門が発火していない状態を、門が自分で失敗として言う。

## この決定が及ばないところ

- **「主張は在るが、弱い」には及ばない。** `assert.ok(true)` は字面で見つかるが、
  `assert.ok(x.length >= 0)` のような常に真の主張は一般には判じられない。
- **突然変異の門が、そこを別の角度から見る。** 潰しても落ちない試験は、
  主張が在っても守っていない。**二つの門は別のことを見ている。**
