# 公開前監査で見つかった 24 件を直す

## 変更内容

Marketplace へ出す前に七つの観点で監査を回し、44 件の所見のうち反証を通った 24 件を直す。
決定を含むものが三つ、残りは決定を含まない直しである。

### 決定を含むもの

| 所見 | 決定 |
|---|---|
| 既定のキー割り当てが編集器の中核機能を奪う | ADR-009（既定のキー割り当てを持たない） |
| 実行体を選ぶ設定を作業フォルダから上書きできる | ADR-010（machine scope にする） |
| 統治木が根直下に無いと拡張機能が起きない | ADR-011（onStartupFinished を足す） |

### 決定を含まないもの

配布の仕組み（`vscode:prepublish`・`vsce` の固定・`.vscodeignore` の穴）、
表示の不備（死蔵した訳・全角約物・`lang` 属性・帯の tooltip）、
統治文書の追随（TEST の受入項・ICD の数え違い・NONGOAL の空欄）、
README の読み手の取り違え、devcontainer の設定併合の欠陥。

## 理由（要求元）

いずれも「公開してから利用者が困る」もので、公開の前でなければ直す機会が無い。
特に次の三つは、導入しただけで実害が出る。

- 既定のキー割り当ての強奪は、統治木を持たない利用者にも無条件で効く。
  拡張機能が起動していなくても効く（キー割り当ては静的な寄与であるため）。
- 実行体を選ぶ設定が作業フォルダから上書きできると、配布元不明のリポジトリを開いて
  信頼しただけで任意の実行体が走る。地図を開く操作すら要らない。
- 起動条件が根直下の統治木しか見ないため、`docsRoot` を設定した利用者の環境では
  何も出ない。原因を示すはずの状態の帯すら出ない。
