# 等幅は一段。ADR-013 の「二段」を置き換える

## 背景

`ADR-013` は決定 2 でこう書いている。

> 書体は四段、**等幅は二段**、太さは `400` と `600` の二種。

だが `DESIGN.md` は**一段**と定めており、理由まで書いてある。

> 二段に分けていた（id を 11px、位置を 12px）。分ける理由が無かった。
> 比は 1.09 で、隣り合う段としては見分けが付かない。**一段に畳んだ。**

**畳んだ決定が、どこにも記録されていなかった。** `ADR-013` は
「`DESIGN.md` が意匠の正本である」と決めた文書なので、
**正本が変わったのに、決定の側が古いまま残っていた。**

そして CSS には**等幅の 11px が一箇所残っていた**。

```
11px  .finding .severity, .finding .check
12px  （他の 9 箇所すべて）
```

意匠の門はこれを素通しした——**族を混ぜて検めていた**からである。
`FONT_SIZES` は比例と等幅の和なので、等幅で比例の段（11px）を使っても通る。

## 決定

### 1. 等幅は一段（12px）。`ADR-013` 決定 2 の「二段」を置き換える

**`ADR` は不変である。** `ADR-013` の本文は書き換えない。
**後継の決定を起こして置き換える**（この文書）。

`DESIGN.md` が一段と定めており、CSS も一段に揃えた。

### 2. 書体の段は、族ごとに検める

比例の 13px と等幅の 12px は「隣り合う段」ではない。
**検めるときも族を分ける。** 混ぜると、等幅で比例の段を使っても通る。

```
not ok - 等幅が DESIGN.md の等幅の段だけを使う（族を混ぜない）
    等幅の段（12px）の外を使っている
```

門を足し、**実際に 11px を捕まえてから**直した。

## 却下した選択肢

### 却下 1 — `ADR-013` の本文を書き換える

「二段」を「一段」に直せば一行で済む。却下した。

**`ADR` は不変の決定である。** 上流の規律は「マージ済みの変更は、
後続の変更で戻すのではなく**後継の決定を起こして置換する**」と定めている。
書き換えると、**なぜ二段だったのかが読めなくなる。**

### 却下 2 — 11px の等幅を残し、`DESIGN.md` を二段へ戻す

CSS を直さず、正本を実体に合わせる手も在る。却下した。

**`DESIGN.md` が畳んだ理由は実測である**——比 1.09 は見分けが付かない。
実体に合わせて正本を戻すと、その実測を捨てることになる。

## 帰結

- 等幅の段は 12px の一つだけになる。CSS の 10 箇所すべてが揃う。
- 意匠の門が族を分けて検める。**混ぜたまま通る道が閉じる。**

## この決定が及ばないところ

- **比例の段には及ばない。** 四段（11・13・15・20）のままである。
- **`ADR-013` の他の決定には及ばない。** 置き換えるのは決定 2 の「等幅は二段」だけである。
