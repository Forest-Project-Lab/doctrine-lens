# 数を出したら行き先も出す。行き先が無いなら、無いと言う

## 背景

`SPEC-006` は「畳んだら必ず件数を書く。隠すことは抽象ではない」と定めている。
その規律に従って脚注はこう出していた。

```
この画面のどこにも出していない所見が 4 件
```

**数は書いた。だが読み手は次に何もできない。**

`ADR-017` はこれを「次の変更で扱う」と残していた。実測すると、
**この数は性質の違う二つを畳んでいた。**

| 種類 | 実体 | 読み手が知りたいこと |
|---|---|---|
| 文書に属さない | 上流の 5 検査（`guard_liveness_gap`・`unregistered_document`・`near_duplicate`・`glossary_seed_drift`・`memory_shadow`）は `doc_id` を空で挙げる | **どの起点を開いても出ない** |
| 起点に繋がらない文書に付く | 起点 `SPEC-005` のときの `REQ-001` の所見 | **どの文書を開けば出るか** |

実測（人工の所見を足して確かめた）:

```
起点 SPEC-005: 出ていない所見 1 件（文書に属さない guard_liveness_gap）
起点 REQ-001 : 出ていない所見 0 件（同じ所見が行に出た）
```

**`CHANGE-006` で「繋がらない 43 件」を三つに割ったのと、同じ誤りが所見の側に残っていた。**
`ADR-017` 決定 1 は「一つの数に、性質の違う二つを畳まない」と書いてある。
**規律を決めても、それがどこまで及ぶかを機械が見ていなければ、次の場所で静かに破れる。**

## 決定

### 1. 数を出したら、行き先も出す

畳んだものの件数を出すとき、**そこへ行く手立てを併せて出す。**
件数だけを出して読み手に手が無い状態を、「隠していない」と呼ばない。

行き先はこの画面が既に持っている一つだけ——**文書の id** である。
id は押せる。押すとその文書が開き、**開いた瞬間にそれが起点になる**
（起点はカーソルから決まる。`ADR-012`）。**新しい操作子を作らない。**

### 2. 行き先が無いなら、「無い」と言う

行き先を作れないものに、作れるふりをしない。

文書に属さない所見は、**どの起点を開いても明細に出ない。**
それは欠陥ではなく、この画面の問いの外に在るということである。
`ADR-012` が予定した三枚目「木そのものの点検表」の担当である。

したがってこう書く。

```
起点に繋がらない 2 文書に所見が付いている: REQ-001 · TEST-002
この画面の問いに属さない所見が 1 件（どの文書にも紐づかない）
```

**「属さない」を明示する。** 「出していない」とだけ書くと、
読み手は「探せばどこかで出る」と読む。出ない。

### 3. 属するかどうかを、検査名で判じない

上流の 5 検査の名前を実装に書くと `REQ-003` の破れになる。
**`doc_id` が空かどうか**だけで分ける——上流が返す値で判じる。

`refs` にだけ id を持つ所見は「属する」側へ入れる
（`findingsFor` が既に `doc_id` と `refs` の両方で引いている）。

## 却下した選択肢

### 却下 1 — 出ていない所見の文を全部脚注に並べる

行き先の代わりに中身を出せば、読み手は判断できる。却下した。

明細の問いは「これを変えたら、何を、どの順で直すことになるか」である。
**起点に繋がらない文書の所見の中身は、その問いの答えではない。**
280px の紙面をそれで埋めると、明細そのものが押し出される。

id だけを出す。中身が要るなら、その文書を開けば起点になって全部出る。

### 却下 2 — 「木そのものの点検表」をいま作る

文書に属さない所見の置き場が無いなら、三枚目を作ればよい。却下した（いまは）。

`ADR-012` の予定表を根の無い状態で追い越さない。
**まず「属さない」と言えるようにする。** 三枚目が要ることは、
そう言い続けても読み手が困ると分かってから決める。

### 却下 3 — 属さない所見を数えるのをやめる

出ないものを数えても仕方がない。却下した。

`SPEC-006`「畳んだら必ず件数を書く。隠すことは抽象ではない」に反する。
**出ないことと、無いことは違う。** 数えて、出ないと言う。

## 帰結

- 「4 件ある」と言われた読み手が、**その 4 件のうち行ける分へ行ける。**
- 行けないものは、行けないと分かる。**探して見つからない時間が消える。**
- 画面は増えない。操作子も増えない。脚注に押せる id が並ぶだけである。

## この決定が及ばないところ

- **文書に属さない所見の中身には及ばない。** 件数と「属さない」ことだけを言う。
  中身を見る場は `ADR-012` の三枚目である。
- **所見の重さによる並べ替えには及ばない。** どの文書から見るべきかは、
  この画面が答える問いではない。
