# 部品の表に指紋を持たせることの影響

## 実測

| 何 | 前 | 後 |
|---|---|---|
| `IMPL-001` の指紋 | **0 本** | **7 本** |
| 表が名指すのに印の無い実装 | **7 件（1747 行）** | **0** |
| 単体試験 | 232 | **233** |

**両方向で赤くなることを確かめた。**

```
部品の表が名指すのに、印で囲まれていない実装が在る          ← 印を外したとき
IMPL-001 の印を持つのに、部品の表に載っていない実装が在る    ← 表に無いものへ印を打ったとき
```

## 順序の不変条件

**印を先に打ち、指紋を後で取る。** 逆順だと、取った指紋が空になる。

**行頭で判じる。** 「`doctrine:begin IMPL-001` を含むか」で数えると、
**門が自分自身を誤検出する**——この門の注釈がその文字列を含んでいる（実測でそうなった）。
`CHANGE-013` の「括弧の数で本体を切って、正規表現リテラルに騙された」と同じ形である。
**新しい門の最初の判定は、疑ってから信じる**（`ADR-024` 決定 5）。
