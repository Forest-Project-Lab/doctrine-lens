# 写しを撮る前に掃除することの影響

## 影響する文書

| 文書 | 何を直したか |
|---|---|
| `SPEC-006` | 受入 34（撮る前に消す。消した枚数を数で言う） |
| `TEST-006` | 対応表に一行、退行観点に一項 |
| `IMPACT-018` | 新設（この文書） |

**新しい決定は立てない。** `ADR-017`「画面は確かめたことだけを言う」を、
**撮っていない画面の写しに当てるだけ**である。

## 影響する実装

**無い。** 門だけである。

## 影響するテスト

単体試験は増えない。**受入 34 の受け持ちは `npm run preview` である**
（`TEST-006` の対応表に「画面側」と宣言してある）。走行の前後で
`.preview/shots/` の中身が入れ替わることを、`tools/shoot-preview.mjs` が
撮る前に消して数で言う。宣言した受け持ちは CI の「実物の画面」の段に在る
（`CHANGE-019`）ので、手元で走らせ忘れても赤くなる。

## 実測

| 何 | 前 | 後 |
|---|---|---|
| `.preview/shots/` の写し | **18 枚**（うち **9 枚が地図時代**・4.8 日前） | **9 枚**（すべてその走行のもの） |

```
前の走行の写し 18 枚を消した。
写しを /workspaces/doctrine_lens/.preview/shots に書いた。誤り 0・食い違い 0。
```

## 工数見積

**事後に立てた見積は置かない**（`ADR-017`。確かめたことだけを言う）。
この変更に先立つ見積は無い。見つけたその巡で直し、PR まで通した。
実際に動いた量は `4a45762`——23 ファイル・+565／−39。この一つのコミットには変更が 2 件載っているので、下の数は 2 件の合計である。

## 順序の不変条件

**撮り始める前に一度だけ消す。** 撮り終えてから消すと、
走行が途中で落ちた回の「途中まで撮れた」状態まで消える。**原因を読む手掛かりを消さない。**

**消す範囲を自分の出力先の `.png` に限る。** 外へ手を出さない。
