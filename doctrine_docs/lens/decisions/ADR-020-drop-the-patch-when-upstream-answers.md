# 上流が答えたら、継ぎをその場で捨てる

## 背景

上流に無いものを補うため、二つの継ぎを置いていた。

| 継ぎ | 何をしていたか | 大きさ |
|---|---|---|
| `src/doctrine/titles.ts` | 上流の内部モジュール `_frontmatter` を `python3 -c` で直接呼び、題名を補う | 137 行 |
| `affectedNeighbours` の畳み | `[src, dst]` を無向の鍵にして、両端書きを自分で一本に畳む | 判断そのもの |

`trace_exempt` の `out/` `dist/` も、`trace-index.py` が `.gitignore` を見ないための継ぎだった。

doctrine 0.8.0 が三つとも答えた。実測で確かめた。

| 上流の変更 | 実測 |
|---|---|
| 節点の白名簿を捨て、組み立てが入れた項をすべて返す | 8 項 → **14 項**。`title` が載る |
| `trace-index.py` が git に訊く | 範囲 30 → **23 件**、`.gitignore` 配下が **0** |
| 辺に `mirrored`（両端書きの印） | 辺 104 本のうち **20 本** |

**上流はこちらが頼んだより深いところを直した。** こちらは「`title` を足してほしい」と
書いたが、上流は白名簿という仕掛けそのものを捨てた。上流の言葉を引く。

> 以前は八項の白名簿で絞っており、**正本がどこにも無いまま組み立てと別々に手で保つ形**に
> なっていた。そして実際にずれた——組み立てが四項を足した後も白名簿は八項のままで、
> **必須項の題名は最初から集められてさえいなかった。**

## 決定

### 1. 上流が答えたら、その回で継ぎを捨てる

継ぎを残す判断を「あとで」に送らない。**上流が答えた変更と同じ回で捨てる。**

理由は三つある。いずれも実測できる。

- **費用が消えない。** `titles.ts` は統治木を二度歩いていた（実測 324ms）。
- **契約でないものに依り続ける。** `_frontmatter` は上流の内部モジュールである。
  名前が変われば壊れる。**上流はそれを契約だと言っていない。**
- **判断がこちらに残り続ける。** 畳んでよい理由をこちらが持つと、
  道具ごとに同じ木が違う形に見える。

### 2. 継ぎを置くときは、捨てる条件を書く

新しい継ぎを置くとき、**何が起きたら捨てるかを同じ文書に書く。**
書かない継ぎは置かない。

`ADR-018` は書いていた——「上流へは issue を立てた（`doctrine#149`）。**届いたらこの層は捨てる**」。
そのおかげで、捨てるべきかを議論せずに済んだ。

### 3. 上流が返した判断を、こちらで作り直さない

`mirrored` は「両端書きである」という**事実**である。上流が持つ。

ただし「どちらを理由として見せるか」（依存か影響か）は**画面の判断**であり、
`ADR-012` が決めている（依存を残す）。**事実は上流、見せ方はこちら。** この線を保つ。

## 却下した選択肢

### 却下 1 — `titles.ts` を残し、上流が返せなかったときの控えにする

上流が題名を返さない木（古い版のプラグイン）でも動くようにしたい。却下した。

**版の差を実装が吸収し始めると、どの版で何が起きるかを実装が知ることになる。**
それは上流の規則を写す一種である（`REQ-003`）。
題名が取れなければ id へ落ちる仕掛けは既に在り、それで足りる。

### 却下 2 — `trace_exempt` の `out/` `dist/` を残す

消しても害は無いが、残しても害は無い。却下した（消す）。

**同じ事実を二箇所に持つのをやめるのが、この変更の目的である。**
`.gitignore` だけを直した人の木で静かに壊れる形を、こちらの木にも残さない。

## 帰結

- 実装が 137 行減る。統治木を歩くのが一度になる。
- 上流の内部モジュールへの依存が一つ消える。
- 「畳んでよい」の根拠が上流に在る。道具が違っても木が同じ形に見える。

## この決定が及ばないところ

- **上流がまだ答えていない三本には及ばない**（`doctrine#152`・`#153`・`#154`）。
  コア／支援／汎用の分類、製品の目的を置く型、雛形の節の検査。
  **これらには継ぎを置いていない**——置けば正本が二つになるためである。
  上流が動くまで、こちらでは何もしない。
