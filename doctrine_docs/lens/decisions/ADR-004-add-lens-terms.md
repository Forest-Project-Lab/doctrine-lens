# レンズ・深度・地図・節点・辺 を承認語に加える

## 背景

lens ドメインは、統治木を図として描く。描くために五つの語が要る。
用語辞書の正本にはこの五語が無い。ICD-001 はこの五語を公開する語として宣言している。
宣言と辞書が食い違ったままにはできない。

このうち「地図」と「レンズ」は、既存の承認語「投影」「ビュー」と紛れる恐れがある。
三者の境目を辞書の上で決めておく必要がある。

## 却下した選択肢

**辞書に加えず、ICD の宣言を取り下げる。** 語を増やさずに済む。
しかし五語は実装と画面と文書のすべてに現れる。辞書に無ければ、
同じものを指す別の言い方が各所に生まれる。用語統一の要求 R6 が守れない。

**「地図」を使わず「投影」で通す。** 承認語を増やさずに済む。
しかし投影は「手で保守しない派生表示」であり、`_system/overview.md` のような文書を指す。
画面に描く図は文書ではない。同じ語で二つを指すと、
「投影ドリフト」がどちらの話かを読み手が判じられなくなる。

## 決定

次の五語を承認語として用語辞書に加える。「地図」は文書ではなく画面に描く図に限って使う。

| 語 | 意味 |
|---|---|
| レンズ | 色・絞り・配置・深度の四つの値の組 |
| 深度 | 地図が示す細かさの段。L0 から L3 |
| 地図 | 統治木を節点と辺として画面に描いた図。文書ではない |
| 節点 | 地図の上で一つの対象を表す印 |
| 辺 | 地図の上で節点どうしの関係を表す線 |

## 帰結

- ICD-001 の「公開する用語」と用語辞書が一致する。
- 「投影」は文書、「地図」は画面の図、「ビュー」は人が手で書いた解釈、という三分が辞書の上で決まる。
- 用語チェッカーはこの五語を未定義語として弾かなくなる。
- 今後この五語の意味を変えるときは、この ADR を置換する新しい ADR が要る。
