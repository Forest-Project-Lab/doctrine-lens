# 決定に行き先を書くことの影響

## 影響する文書

`ADR-001`・`006`〜`011` の frontmatter に `impacts` を書いた。**本文は一字も触っていない**——
`ADR` は不変であり、`impacts` は決定の中身ではなく**決定がどこへ効くかの宣言**である。

| | 書いた `impacts` | 根拠 |
|---|---|---|
| `ADR-001` | `SPEC-001` | 上流への橋がこの決定を引いている |
| `ADR-006` | `SPEC-001` | 同上 |
| `ADR-007` | `SPEC-005`・`IMPL-001` | 原文の規律を引いているのはこの二つ |
| `ADR-008` | `SPEC-001`・`TEST-001` | 二つの拍の受入は `TEST-001` に在る |
| `ADR-009` | `SPEC-005`・`IMPL-001` | 鍵割り当ての不在を引いている |
| `ADR-010` | `SPEC-001` | 設定の scope を引いている |
| `ADR-011` | `SPEC-001` | 起動条件を引いている |

**辺を捏造していない。** 「その文書が本文でこの `ADR` を引いているか」を実測し、
引いている先だけを書いた。

## 影響する実装

**無い。**

## 影響するテスト

**無い。** 「辺を持たない現行の決定」を門にするかは**測ってから決める**（`CHANGE-020`）。
`CTXMAP`・`OVERVIEW`・`DECIDED`・`NONGOAL`・`REQ-000` は辺を持たないのが正しい形なので、
型で除くだけの門は擬陽性を生む。

## 実測

| 起点 | 前 | 後 |
|---|---|---|
| `ADR-008`（二つの拍） | **0 件** | **13 文書・コード 18 か所・波 5** |
| `ADR-001`（上流へ委ねる） | 0 件 | 13 文書・コード 18 か所 |
| `ADR-007`（原文は英語） | 0 件 | 5 文書・コード 7 か所 |
| `ADR-010`（設定の scope） | 0 件 | 13 文書・コード 18 か所 |
| 辺を持たない現行の文書 | **13 件** | **6 件** |

残る 6 件（`CTXMAP-001`・`DECIDED-001`・`NONGOAL-001`・`OVERVIEW-001`・`OVERVIEW-002`・
`REQ-000`）は、**辺を持たないのが正しい形**である——投影と横断の正本であり、
`ADR-026` が「辺では指さず、本文で参照する」と決めている。

## 工数見積

**事後に立てた見積は置かない**（`ADR-017`。確かめたことだけを言う）。
この変更に先立つ見積は無い。見つけたその巡で直し、PR まで通した。
実際に動いた量は `e06a947`——14 ファイル・+286／−8。

## 順序の不変条件

**逆から測る。** 「この `ADR` は何を縛っているか」を本文から読むと、
七本のうち六本は自分では何も引いていない（`ADR-006` だけが `SPEC-001` を引く）。

**「どの文書がこの `ADR` を引いているか」を測る。** それが実際に効いている先である。
決定の側から想像して書くと、辺を捏造することになる。
