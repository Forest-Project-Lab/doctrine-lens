# 自分で作った語を、辞書へ足す

## 背景

利用者に「門待ちって何でしょうか？」と訊かれた。**答えが辞書に無かった。**

測ったら、統治文書で頻繁に使っている語のうち四つが承認語でない。

| 語 | 使用 | 紛らわしい承認語 |
|---|---|---|
| `上流` | 340 回 | — |
| `画面` | 246 回 | **`ビュー`**（＝人が手で書く体系外の文書） |
| `門` | 160 回 | **`ガード`**（＝違反を拒む Hook）・**`検査`**（＝上流の判定） |
| `試験` | 150 回 | **`検査`** |

### いちばん効くもの — `検査` と `試験`

辞書は `検査` を「上流の監査が走らせる判定の一つ」と定義している。
こちらが書いた試験は**別物**であり、数も別である。

```
上流の docs-audit を 2026-08-03 に実行（36 検査）
単体 228 件・突然変異の表 70 行
```

**同じ語で読まれると、両方の数が意味を失う。**
`ADR-014` は「数を代弁する語を数量の位置に置かない」と決めたが、
**数が何を数えたものかが読めなければ、数そのものが読めない。**

### なぜ機械が咎めなかったか

上流のリンタは**地の文を判じない**（`_termcheck` が明記している——
「judging the 地の文 is doc-review's job, not the linter's」）。
未承認語を弾くのは、借用語・カルク・禁止同義語の形に当たるものだけである。

**仕様どおりであり、上流の欠陥ではない。** 日本語の地の文を機械が判じると
擬陽性が支配する。辞書へ足すのはこちらの仕事である。

## 決定

### 1. 四語を辞書へ足す。**紛らわしい相手を、意味の中に書く**

```
| 上流 | 規則と判定の正本を持つ doctrine プラグイン本体 | 本体、親、コア、doctrine 側 |
| 画面 | 拡張機能が編集器に出す面（人が手で書くビューと混同しない） | パネル、UI、画面表示、view |
| 門   | 壊れたら赤くなる仕掛け。試験・監査・写し・突然変異の総称
        （違反を拒む Hook であるガードと混同しない） | ゲート、チェック、関門、CI |
| 試験 | この製品が自分で書いた検証（上流の監査が走らせる検査と混同しない） | テスト、ケース、スイート |
```

**「〜と混同しない」を意味の側に書く。** 禁止同義語の列は「使うな」しか言えないが、
本当に危ういのは**似ているが別のもの**である。`画面` と `ビュー`、`門` と `ガード`、
`試験` と `検査` は、どれも「使うな」ではなく「別だ」と言う必要がある。

### 2. 語を作ったら、その一周のうちに足す

`CHANGE-007`／`ADR-018` で 6 語を足したのに、**次の四周でまた四語足りなくなった。**
語は書きながら増えるので、後回しにすると必ず溜まる。

**新しい語を画面か文書に出したら、その一周のうちに辞書へ足す。**

### 3. 足し忘れを機械で探さない（いまは）

**測ってから決める。** 実測で、漢字の連なりを数えると動詞の語幹（`出`・`行`・`直`）が
上位を占め、意味を持つ語との区別が字面では付かなかった。

上流が「地の文は判じない」と決めているのと同じ理由である。
**判じられない範囲を門にしない**（`ADR-024` 決定の形）。

代わりに、`ADR-018` が既に置いた仕掛けが効く——**画面に出た語の定義を脚注に出す。**
辞書に無い語は脚注に出ないので、**読み手が「この語の定義が無い」と気づける。**

## 却下した選択肢

### 却下 1 — 上流へ「地の文も検めてほしい」と頼む

未承認語を弾く機能が在るなら、地の文にも当ててほしい。却下した。

**上流は意図してそうしていない。** `_termcheck` が明文で
「地の文を判じるのは doc-review の仕事」と書いている。
**自分の木で足りることを上流へ頼まない**（`CHANGE-010` と同じ判断）。

### 却下 2 — 語を増やさず、使うのをやめる

`門` を毎回「壊れたら赤くなる仕掛け」と書けば、辞書を増やさずに済む。却下した。

**辞書が在る理由そのものを否定する。** 一つの意味を一つの語で運ぶために辞書が在る。
160 回それを書き下すのは、語彙を持たないことではなく、語彙を捨てることである。

### 却下 3 — `画面` を `ビュー` に寄せる

承認語が既に在るなら、そちらを使えば語を増やさずに済む。却下した。

**別のものである。** 辞書の `ビュー` は「正本をある時点で人向けに解釈した
**体系外の文書**」であり、`README` がそれに当たる。拡張機能が編集器に出す面ではない。
**似た語へ寄せると、二つの概念が一語に潰れる。**

## 帰結

- 承認語が 33 → **37** になる。
- 画面の脚注に、これらの語の定義が出るようになる（`ADR-018` の仕掛けが自動で効く）。
- `検査 36` と `試験 228` が、別のものを数えていると読めるようになる。

## この決定が及ばないところ

- **足し忘れを機械が見つけることには及ばない**（決定 3）。
  次に足りなくなったときに、また測ってから決める。
- **上流の語彙には及ばない。** 型・status・置き場所は上流が正本である（`REQ-003`）。
