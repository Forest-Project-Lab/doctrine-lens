# 前提の行き先を出すことの影響

## 影響する文書

| 文書 | 何を直したか |
|---|---|
| `SPEC-006` | 脚注の見本に直の前提。制約に「前提も同じである」。受入 33 |
| `TEST-006` | 対応表に二行、退行観点に二項 |
| `IMPACT-016` | 新設（この文書） |

**新しい決定は立てない。** `ADR-019`「数を出したら行き先も出す」を、
**当てていなかった箇所に当てるだけ**である。新しい規律は要らない。

## 影響する実装

| ファイル | 何を変えたか |
|---|---|
| `src/model/consequence.ts` | `Consequence.premisesDirect`（逆向き隣接の一歩） |
| `src/model/view.ts` | 脚注に直の件数を差し込み、`premisesAt` を運ぶ |
| `src/shared/protocol.ts` | `RowView` ではなく画面全体に `premisesAt` |
| `src/webview/main.ts` | 押せる行き先として描く（所見の行き先と同じ形） |
| `src/l10n.ts`・`l10n/bundle.l10n.ja.json` | 脚注の文に `{1}` を足す |

## 影響する門

| 門 | 何を足したか |
|---|---|
| `src/test/consequence.test.ts` | 受入 33・33b（2 本） |
| `tools/mutate-check.mjs` | 2 行（行き先を出さない／推移の全部を並べる） |
| `tools/shoot-preview.mjs` | 実物の画面で「数を出したのに行き先が無い」を落とす |

## 実測

| 何 | 実測 |
|---|---|
| 前提を持つ起点 | 52 / 85 |
| 推移の前提 | 最大 **43**（`TEST-006`）／中央 6 |
| 直の前提 | 最大 **31**（`SPEC-006`）／中央 **1** |
| 直が 8 件を超える起点 | **4 / 52（8%）** |
| 280px での高さ（`SPEC-006`・31 件） | **248px**（脚注全体 616px のうち） |
| 単体試験 | 228 → **230** |
| 潰しの表 | 70 → **72** |

**中央が 1 件なので、ふつうの起点では一行しか増えない。**
最大の `SPEC-006` でも 248px であり、縦に伸びるだけで横には溢れない。

## 順序の不変条件

**測ってから並べ方を決める。** 最初は「直の前提は最大 7」と測ったが、
それは `depends_on` の辺だけを見ていた誤りで、**`impacts` で指してくる `CHANGE` を
落としていた**。正しくは最大 31 である。

実装してから 280px で高さを測り、**248px なら並べられる**と判じた。
測る前に「多すぎる」と決めていたら、行き先を出さないままだった。
