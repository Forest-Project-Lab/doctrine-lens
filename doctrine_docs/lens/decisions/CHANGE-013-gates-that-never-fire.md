# 発火していない門が、まだ三つ在る

## 何が起きているか

`ADR-017` は「自分の門が緑であることを正しさの証拠にしない」と決めた。
`CHANGE-010` の一周で、その決定に従って独立の走査をかけたところ、
**門そのものが発火していない箇所**が挙がった。

四つ見つかり、**そのうち三つは `CHANGE-010` の中で塞いだ。**

| 塞いだもの | 何が起きていたか |
|---|---|
| 写しの門 `statusAgrees` | 既定の起点では非現行も status 欄も 0 なので、毎回 `0 === 0` で通る。**行の status 欄を丸ごと消しても緑だった** |
| 表を読む門の引用符 | 単引用符・逆引用符で書いた行が、宣言の数え方と読み取りの数え方の**両方から同時に**落ちる |
| 孤児の門 `006-26` | 注釈を落とさずに数えるので、**この試験自身の注釈**が三つの項を名指しているせいで、実装が一つも読んでいなくても通る |

**残る三つを、この変更で塞ぐ。**

| 場所 | 何が起きているか |
|---|---|
| `tools/shoot-preview.mjs` 07-notice の段 | 期待が `{ overflow: [], placeholders: [] }` だけで、**通知が出たことを一つも主張していない。** 通知の描画を殺しても両方とも空のまま通る |
| `src/test/paths.test.ts` symlink の封じ込め | 主張が `if (found !== null)` の中にしか無く、この環境では `locateDocsRoot` が `null` を返すので**本体が一度も走らない。** 零件の主張で通っている |
| `src/test/cadence.test.ts` 見本 | `findings: staleIds.size >= 0 ? [] : null` は `Set.size` が負にならないので**常に真**。両方の場合を踏んでいるように読めて、片方しか作らない |

## 変更内容

1. 三つを塞ぐ。**塞いだあと、故意に壊して赤くなることを両方向で確かめる。**
2. 「門が発火していないこと」を、門が自分で言える形にする。
   `statusAgrees` で採った形——**不変条件を試せない状態を失敗として扱う**——を
   他の門へも広げられるかを見る。

## 見えている難所

**「発火していない」は、緑と見分けが付かない。** 通らない道を通ったことにする門は、
落ちないので気づかれない。`CHANGE-010` では独立の走査が挙げたが、
**毎回そうするわけにはいかない。**

零件の主張・常に真の条件・両側が零の一致——この三つは字面で探せる。
門にできるかを検討する。

## 理由（要求元）

`ADR-017` 決定 2。`REQ-001`——門が守っていないものは、辿れても正しいとは限らない。

### 三つとも、壊して赤くなることを確かめた

```
長い通知（280px）: notice が null（期待: v !== null && v.text.length > 0 && v.error === true）
通知の文が画面に出ていない: null                      ← 通知の描画を殺したとき exit=1
通知の文が画面に出ていない: {"text":"The\nTraceback…  ← 上流の文を切り詰めたとき
主張を一つも持たない試験が在る: status.test.ts: …     ← 主張の無い試験を一本足したとき
```

### 見積が外したこと — 門を作るときに、門が嘘をついた

「主張を一つも持たない試験」を探す門を、最初は**括弧の数で本体を切って**書いた。
正規表現リテラル `/[{;]/` の `{` に騙されて、**主張を持つ試験を三本「持たない」と報せた。**

```
主張が無い: src/test/design.test.ts :: 彩度のある色が、記号の一文字にだけ載っている
```

その三本は `assert.deepEqual` を持っている。**門の言い分を、門を信じる前に確かめた。**
行頭の `test(` で区切る形へ直したら 0 件になり、そこで初めて門にした。

`ADR-024` 決定 5 として書いた——**新しい門の最初の判定は、疑ってから信じる。**

### 却下したこと — 零件の主張を機械が全部見つける

「条件の中だけに主張が在る」を字面で探せば網羅できる、と考えた。却下した。

**擬陽性が支配する。** `if (!x) return;` のあとの主張は正当である。
いま門にできたのは「主張を一つも持たない試験」だけで、これは字面で確実に判じられる。
**判じられる範囲だけを門にする。**
