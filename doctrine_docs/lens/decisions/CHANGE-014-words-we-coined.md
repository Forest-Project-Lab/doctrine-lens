# 自分で作った語が、辞書に無い

## 何が起きているか

利用者に「門待ちって何でしょうか？」と訊かれた。**答えが辞書に無かった。**

測ったら、統治文書で頻繁に使っている語のうち四つが承認語でない。

| 語 | 使用 | この木での意味 | 紛らわしい承認語 |
|---|---|---|---|
| `上流` | 340 回 | doctrine プラグイン本体。規則と判定の正本 | — |
| `画面` | 246 回 | この拡張機能が編集器に出す面 | **`ビュー`**（＝人が手で書く体系外の文書）と別物 |
| `門` | 160 回 | 壊れたら赤くなる仕掛け（試験・監査・写し・突然変異） | **`ガード`**（＝Hook）・**`検査`**（＝上流の判定）と別物 |
| `試験` | 150 回 | こちらが書いた試験 | **`検査`**（＝上流の監査が走らせる判定の一つ） |

### いちばん効くもの — `検査` と `試験`

辞書は `検査` を「上流の監査が走らせる判定の一つ」と定義している。
こちらが書いた試験は**別物**であり、数も別である。

```
上流の docs-audit を 2026-08-03 に実行（36 検査）
単体 221 件・突然変異の表 71 行
```

**同じ語で読まれると、両方の数が意味を失う。**

### なぜ機械が咎めなかったか

上流のリンタは**地の文を判じない**（`_termcheck` が明記している——
「judging the 地の文 is doc-review's job, not the linter's」）。
未承認語を弾くのは、借用語・カルク・禁止同義語の形に当たるものだけである。

**仕様どおりであり、上流の欠陥ではない。** 辞書へ足すのはこちらの仕事である。

## この変更でやること

1. 四語を `GLOSSARY-001` へ足す。禁止する同義語も書く
   （`門` に対する「ゲート」「チェック」、`上流` に対する「本体」など）。
2. `ADR-018` が定めた形に従い、**決定として記録してから**表を更新する。
3. `画面` と `ビュー`、`門` と `ガード`と`検査`、`試験` と `検査` の**線を辞書に書く。**
   紛らわしいものは、紛らわしいと書いておく。

## 却下する見込みのもの

- **上流へ「地の文も検めてほしい」と頼む。** 上流は意図してそうしていない。
  日本語の地の文を機械が判じると擬陽性が支配する。**自分の木で足りることを上流へ頼まない**
  （`CHANGE-010` と同じ判断）。
- **語を増やさず、使うのをやめる。** `門` を毎回「壊れたら赤くなる仕掛け」と書くのは、
  辞書が在る理由そのものを否定する。

## 見えている難所

**`CHANGE-007`／`ADR-018` で 6 語を足したのと同じことが、また起きている。**
語は書きながら増えるので、一度足しても次の一周でまた足りなくなる。

**足す作業を繰り返すのではなく、足し忘れに気づく仕掛けが要るのではないか。**
ただし上流が「地の文は判じない」と決めている以上、機械にできることは限られる。
この変更では四語を足し、**仕掛けの要否は測ってから決める**（先に一般化しない）。

## 要求元

`REQ-003`「統治の規則を二重定義しない」——語彙の正本は辞書である。
`ADR-018`「辞書は読む。持たない。辞書に無い語を説明したくなったら、辞書へ足す」。

## 影響の初期見積

| 区分 | 見積 |
|---|---|
| 書き直す文書 | `GLOSSARY-001`（4 語を追加） |
| 新しく作る文書 | `IMPACT-014`・`ADR-025` |
| 触る実装 | 無し |
| 触る門 | 無し（辞書は上流のパーサで読む。語が増えれば画面の脚注に自動で出る） |

## 実施の記録

2026-08-03 に一周を終えた。

| 何 | 前 | 後 |
|---|---|---|
| 承認語 | 33 | **37** |
| 統治文書で 25 回以上使うのに辞書に無い語 | 4 | **0** |
| 画面の脚注に出た語（起点 `SPEC-005`） | `帰結`・`明細`・`検査` | **`上流`・`帰結`・`明細`** |

**足した語が、その場で画面に出た。** `ADR-018` が置いた仕掛け——
「画面に出た文字列と辞書の承認語を突き合わせて、出た語だけ定義を並べる」——が
実装を一行も触らずに効いている。

### 見積が外したこと — 「混同しない」を意味の側に書く必要が在った

禁止同義語の列は「使うな」しか言えない。だが本当に危ういのは**似ているが別のもの**である。

| 語 | 似ているが別のもの |
|---|---|
| `画面` | `ビュー`（＝人が手で書く体系外の文書。`README` がそれ） |
| `門` | `ガード`（＝違反を拒む Hook） |
| `試験` | `検査`（＝上流の監査が走らせる判定の一つ） |

**三つとも「使うな」ではなく「別だ」と言う必要が在った。** 意味の中に括弧で書いた。

### 却下したこと — 足し忘れを機械で探す

漢字の連なりを数えて未定義の語を探そうとしたが、実測で上位を動詞の語幹
（`出` 490 回・`行` 342 回・`直` 285 回）が占め、**意味を持つ語との区別が字面で付かない。**

上流が「地の文は判じない」と決めているのと同じ理由である。
**判じられない範囲を門にしない**（`ADR-024` の形）。

代わりに `ADR-018` の仕掛けが効く——辞書に無い語は脚注に出ないので、
**読み手が「この語の定義が無い」と気づける。**
