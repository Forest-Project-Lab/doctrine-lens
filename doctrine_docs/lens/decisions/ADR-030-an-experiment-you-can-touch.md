# 触れない検証は進まない — 実験を同梱し、図の禁止を帰結の画面に限る

## 背景

System Map の検証(上流 issue 204)は Phase 1 を「検証継続」で固定した。機械検査(M 層)は
実判定になり、俯瞰レビューの合格条件も通ったが、人間検証(H 層)は独立した被験者が
確保できず `UNASSESSED` のままである。検証の産物は実験ブランチの静的 HTML であり、
編集器の利用者(所有者を含む)からは一手間遠かった。

所有者が判断した(2026-08-04): 実験として触りたい。H 層は当分来ないので暫定的に可とする。
最小性(上流 issue 210)は別タスクであり拡張機能化は許可される。一旦ここまでで main に上げる。

## 却下した選択肢

**H 層の合格まで同梱しない(ADR-029 の読みのまま)。** 独立した被験者の当てが無い以上、
これは無期限の停止と同じである。触れない検証は使われず、使われない検証は誤読も発見できない。
最初の実利用者の観察を H 層評価として記録する道(DESIGN-001)は、触れる形が在って初めて開く。

**Marketplace へ公開してから触ってもらう。** 公開は不特定の利用者に届く。実験の同梱と
公開の判断は別であり、後者は裁かれていない。

**別の拡張機能として分ける。** 統治木・訳・束ねの足場を二重に持つことになる。読むだけの
一画面のために統治面を増やすのは、最小性の議論(上流 issue 210)を先取りして悪化させる。

## 決定

1. **System Map(実験)を同梱する。** 明示の命令でだけ開く読み取り専用の webview とし、
   候補モデルの静的 HTML を束ねの時点で内蔵する。取得・書き込み・外部通信を持たない。
   既定の挙動(帰結の画面・起動時の活性化)は変えない。
2. **「図を描かない」の範囲を帰結の画面に狭める(理由ごと)。** 旧地図の実測失敗
   (無意味な二軸・同一事実の二重描画)は依存グラフから**導出した**位相図のものであり、
   ADR-012 の理由は帰結の画面に生き続ける。System Map の図は人が絞った意味モデルを
   機械検査の下で描く別条件の別画面である(採用は所有者判断・上流 issue 204)。
3. **これは実験の同梱であり、製品採用ではない。** H 層は `UNASSESSED` のまま画面にもその旨が
   常掲される。本番移管の条件(上流 issue 210)は PAUSED のままであり、この決定はそれを充足しない。

## 帰結

- NONGOAL-001・DECIDED-001 第5項の範囲修正(CHANGE-031)。帰結の画面の規律は不変。
- 最初の実利用者(所有者を含む)の観察が得られたら、H 層評価として
  `research/system-map/usability-tests/` の手順で記録する。
- 正式な製品採用・公開・移管を裁くときは、本 ADR ではなく新しい決定を起こす。
