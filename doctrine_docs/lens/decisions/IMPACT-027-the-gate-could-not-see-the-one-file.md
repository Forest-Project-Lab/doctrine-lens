**独立の走査で挙がった 47 件のうち、反証を生き延びたのは 40 件。**
そのうち高が 3 件で、**三件とも実物で再現した**（模型に直に入力を与えて返り値を見た）。

## 工数見積

**事後に立てた見積は置かない**（`ADR-017`）。六観点の走査を回した直後に
高 3 件を実測で確かめ、同じ巡で直した。実際に動いた量はこの PR の差分が示す。

## 順序の不変条件

**門を先に直し、赤を出してから実装を直す。** 正規表現を直した瞬間に
`src/l10n.ts` が名指しで挙がった。逆順だと「直したから緑になった」のか
「もともと緑だった」のかが読めない。

**既定を置くくらいなら、型に言わせる。** 座標系に既定を持たせると、
呼び手が黙っていても通る。既定を外すと、`src/extension.ts` の二箇所が
その場で型に落とされた——**書き忘れていた場所を、型が名指した。**

**数える側と門が、同じ式を使わない。** 今回見えなかった根はここである。
`CHANGE-022` の「25 のファイル」も、門の `[a-zA-Z/.]` も、同じ読み落としをしていた。
**宣言（人が書いた数）と実測（機械が数えた数）を突き合わせれば、
片方だけが誤っていても落ちる。**
