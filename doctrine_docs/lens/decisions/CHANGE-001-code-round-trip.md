# 文書とコードの往復を加える

## 変更内容

深度 L3 を実装し、文書とコードを双方向に行き来できるようにする。

- コードから文書へ。印が囲む範囲の上に、どの文書の実装かを示し、その文書へ跳べるようにする。
- 文書からコードへ。L2 から L3 へ降り、範囲を選ぶと編集器の該当行が開く。
- 指紋の食い違い（記録した指紋といまのコードの指紋の差）を画面に示す。
- 仕様のうちコードに結ばれていないものを示す。

## 理由（要求元）

ADR-003 は最初のスライスを L0 から L2 に限った。その狙いは「地図は導出される」という
主張を最小の実装で確かめることであり、確かめは済んだ。

いま L3 が無いことで、地図は文書の層で止まっている。要求から実装までを一続きで
たどるという REQ-001 の狙いは、コードに届いて初めて満たされる。

### 要求元

REQ-001（統治木を俯瞰から実装まで連続した深度で見る）の未達部分。
利用者からの明示の依頼（2026-07-28）。

## 影響の初期見積

`dep-graph.py` で列挙した（下の IMPACT-001 が確定版を持つ）。

- SPEC-002 が「L3 は本スライスの対象外」と書いている。この一文を覆す。
- SPEC-002 の逆依存は IMPL-001・SPEC-003・TEST-002 の三つ。
- 新たに上流の `trace-index.py` と `docs-audit.py` を呼ぶ。ICD-001 のデータ契約は
  既にこの二つを挙げているが、「後のスライスで使う」と書いてある部分を改める。
