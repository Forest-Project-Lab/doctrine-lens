# README が自分で書いた規律を、自分の 240 行下で破っていた

## 何が起きているか

`README.md` の 111 行目にこう書いてある。

> The count carries the commit it was taken at, because the tree grows: writing
> this one change added four governance documents and moved the number 67 → 70.
> **A measurement without its basis goes stale in silence.**

その 240 行下、351 行目。

> Measured on this repository (45 documents): `dep-graph` 127 ms, `trace-index`
> 645 ms, `docs-audit` 543 ms, titles 324 ms, registry probe 21 ms.

**刻印が無い。** そして木はいま **106 文書**である。45 で測った数を、
2.4 倍に育った木の README が載せ続けていた。**silence のまま stale になっていた。**

## 何が古びていたか

測り直した（`21131e4` の木・106 文書・三回の中央値）。

| 部品 | 45 文書のとき | 106 文書のいま |
|---|---|---|
| 登録簿 | 21 ms | **17 ms** |
| `trace-index` | 645 ms | **604 ms** |
| `docs-audit` | 543 ms | **2544 ms** |
| 一巡 | 約 1.9 s | **速い拍 2022 ms・遅い拍 3516 ms** |

**監査だけが 4.7 倍になっている。** 木が育つと監査が支配する、というのは
`ADR-008`（拍を二つに分ける）が予期していたことだが、
**その予期が正しかったことを示す数を、README は持っていなかった。**

## 名札が中身と合っていなかった

測る道具を書いている途中で、もう一つ見つけた。
`fetchSnapshot` は dep-graph だけではなく、登録簿・範囲・所見・逆孤児・辞書までを
一度に取る「一巡」である。部品の名で時間を出すと、読み手は
**dep-graph が 3.5 秒かかる**と読む。名札を「速い拍」「遅い拍」へ直した。

## いまの木の話ではない測定を、現在形で書いていた

`## Why this isn't a map anymore` の節に、こう在った。

> The tree **is** 45 nodes, 45 edges, density 0.02.

地図を捨てたときの測定であり、いまの木ではない。言い切りを「〜だった」へ直し、
いまの数（106）を添えた。**いつの話かが分かる形で残す。**

## 変更内容

1. **`tools/measure-tree.mjs` に拍の所要を足す。** 手で測らない。
   五つの部品と二つの拍を、三回の中央値で出す。
2. **README の数を、刻印つきで書き直す。** `21131e4` の木・106 文書。
3. **名札を中身に合わせる。** 「速い拍（監査を除く一巡）」「遅い拍（監査を含む一巡）」。
4. **地図時代の測定を「〜だった」へ直し、いまの数を添える。**
5. **古びていた事実そのものを README に残す。** 消さない——
   `ADR-017`（画面は確かめたことだけを言う）は、直したことも言う。

## 却下する見込みのもの

**README の数を門にする。** 所要の実測は機械ごとに違う（この容器の数であり、
利用者の機械の数ではない）。門にすると、CI の走行機の速さで赤くなる。
却下する。**代わりに、数の出所を道具に一本化した**——手で測らなければ、
次に測るときも同じ形で出る。

**古びた数を消す。** 却下する。「45 文書のときは 543 ms だった」は、
**監査が木の大きさに効く**という主張の根拠である。消すと主張の根拠が消える。

## 見えている難所

**README はビューであり、投影ではない。** 手で保守する。
`docs-audit` の `view_stale` は刻印と正本の `updated` を突き合わせるが、
**中身が正本から離れたことは見ない**（実測——`CHANGE-023` で `SPEC-006` の
`波及先` を直したのに、README の写しは古びたままだった。`CHANGE-025` で見つけた）。

いまの門で捕まるのは、**辞書に触れる古び**（`docs:terms`）と
**刻印つきの行数**（`docs:measured`）だけである。それ以外の中身の古びは、
**人が読んで見つける**。ここは機械にしていない。

## 理由（要求元）

`ADR-021` 決定 5（測った数には刻印を添える）。`ADR-017`。
`CHANGE-025` で README を触ったとき、他の数も見て回って見つけた。
