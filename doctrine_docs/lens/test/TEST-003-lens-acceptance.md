# レンズ文法の受入

## 受入基準への対応

SPEC-003 の受入基準の六項に一対一で対応させる。

| 確かめること | 手立て |
|---|---|
| 一つを変えても残る三つが変わらない | 四つのダイヤルそれぞれについて、変更の前後を比べる |
| 未知の型にも色が付く | 上流が返さない型の値を持つ節点を与える |
| 現行のみで現行でない節点が消える | 現行でない status を持つ節点を含む見本で数える |
| 全て消えても絞りの値が保たれる | どの節点も通さない絞りを与え、値を見る |
| 保存したレンズが再現される | 名前を付けて保存し、別の値へ移してから選び直す |
| 効かない組み合わせで例外が出ない | L0 にレーンを指定し、落ちた先の方式を見る |

## 退行観点

- 色の基準・絞りの条件・配置の方式のいずれについても、値の一覧を持たないこと。
  持てば REQ-003 の破れになり、上流が値を増やしたときに画面だけが古びる。
- 絞りで節点が全て消えたときに、絞りを勝手に緩めないこと。緩めれば、
  読み手は自分が何を見ているのかを見失う。
- 四つのダイヤルの独立を崩さないこと。一つの変更が他へ波及すると、
  REQ-002 が求める「観点の切り替えが軽い」という性質が失われる。

## 合否基準

上表の六項がすべて通ること。独立の確認は四つのダイヤルすべてについて行い、
一つでも波及が見つかれば不合格とする。
