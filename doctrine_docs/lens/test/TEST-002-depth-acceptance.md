# 深度の行き来の受入

## 受入基準への対応

SPEC-002 の受入基準の十項に一対一で対応させる。

| 確かめること | 手立て |
|---|---|
| 降りる操作だけで L0 から L2 へ着く | 見本のグラフで降りる操作を二度呼ぶ |
| 上がる操作の繰り返しで L0 へ戻る | L2 から上がる操作を呼び、深度と焦点を見る |
| 深度を変えても他の三つが変わらない | 変更の前後でレンズの値を比べる |
| L0 の節点の数がドメインの異なり数と合う | 複数のドメインを持つ見本で数える |
| 同じ両端の辺が一本に畳まれる | 同じドメインの組を結ぶ辺を二本持つ見本で、本数と畳んだ数を見る |
| 二度描いて座標が一致する | 同じ入力で配置を二度計算し、全ての座標を比べる |
| 焦点が消えても例外が出ない | 焦点の文書を除いたグラフを与え、戻り先の深度を見る |
| L2 の焦点から L3 へ降りる | コード範囲を持つ文書で降りる操作を呼び、深度と節点を見る |
| L3 から上がると同じ文書の L2 へ戻る | L3 で上がる操作を呼び、深度と焦点を見る |
| 範囲を持たない文書から L3 へ降りられない | 範囲の無い文書で降りる操作を呼び、`null` が返ることを見る |

## 退行観点

- 配置に乱数と時刻を持ち込まないこと。SPEC-002 が課す決定性は、
  地図を版管理の差分として読める状態を保つための前提である。
- L0 でドメインの一覧を自前で持たないこと。上流の節点が持つ値から集める。
  持てば REQ-003 の破れになる。
- 節点が一つも無い深度へ降りられないようにすること。空の画面へ落ちる道を残さない。

## 合否基準

上表の十項がすべて通ること。決定性の確認は、座標の一致を全ての節点について見る。
一つでも異なれば不合格とする。
