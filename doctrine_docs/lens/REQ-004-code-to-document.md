# コードを読んでいるときに、その根拠の文書へ行ける

## 要求文

読み手は、編集器でコードを読んでいる最中に、いま見ている範囲がどの文書の実装かを知り、
その文書へ跳べる。明細の画面を開いていなくてよい。

往復は片方向を二つ並べたものではない。どちらから入っても同じ対応を引けることを言う。
文書から実装へ行けるのに、実装から文書へ戻れないなら、往復は成り立っていない。

この要求が満たされたことは、次の三つで確かめる。

1. 印が囲む範囲を含むファイルを開くと、その範囲の上に結ばれた文書が示される。
2. その示しから、対応する文書を開ける。
3. 記録された指紋といまのコードの指紋が食い違っているとき、その事実が範囲の上に示される。

## 優先度

高。この要求が満たされなければ、辿れる範囲が文書の層で止まり、
要求から実装まで一続きでたどるという REQ-001 の狙いがコードに届かない。

## 受入基準参照

TEST-005

## 出所

上流 doctrine が定めた追跡の終点（doctrine 側 ADR 054）は「注釈の対が囲むコードのテキストの範囲」である。
その範囲は編集器の中に在り、明細の中には無い。範囲を編集器の側で示さなければ、
上流が用意した追跡の終点に読み手が到達できない。
