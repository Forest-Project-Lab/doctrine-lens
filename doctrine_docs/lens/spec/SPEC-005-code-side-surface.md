# コード側の面

## 入出力

入力は SPEC-004 が返す範囲と所見、および編集器が開いているファイル。
出力は、そのファイルの上に重ねる三つである。

### 範囲の見出し

印が囲む範囲の始まりの行に、結ばれた文書を一行で示す。示す内容は次の順に並べる。

| 位置 | 内容 | 押したとき |
|---|---|---|
| 1 | 文書の id と題 | その文書を開く |
| 2 | 指紋の状態 | 食い違っているときだけ出す。押すと取り直し方を示す |
| 3 | 地図で見る | その文書の L2 を地図で開く |

題は上流の節点が持つ値から取る。無ければ id だけを示す。

### 範囲の帯

印が囲む範囲の行に、余白の帯を付ける。帯は範囲の内と外を見分けるためだけのもので、
押しても何も起きない。指紋が食い違っている範囲は、帯の色を変える。

### 命令

| 命令 | 効く場所 | すること |
|---|---|---|
| この範囲の文書を開く | 印が囲む範囲の中に文字入力の位置が在るとき | 結ばれた文書を開く |
| この文書の実装へ跳ぶ | 統治木の文書を開いているとき | 結ばれた範囲へ跳ぶ。複数あれば選ばせる |

いずれも、対応が無いときは無い旨を示して終わる。異常として扱わない。

命令に既定のキー割り当てを付けない（ADR-009）。付けると、拡張機能が起動していなくても
編集器の既定を奪う。到達の手立ては命令パレット・右クリック・見出し・状態の帯で足りる。

## 制約

- 範囲の見出しと帯は、範囲が在るファイルにだけ出す。無いファイルには何も出さない。
- 右クリックの項目は、統治木が見つかっている作業フォルダでだけ出す。統治木を持たない
  プロジェクトの全ファイルに項目を挿し込まない。順も、編集器の既定の項目より後ろに置く。
- 保存を合図に取り直すのは、統治木の中の `.md` か、上流が返した範囲に載っている
  原本のときだけである。作業フォルダの中というだけでは通さない。通すと、無関係な
  一回の保存で速い拍と遅い拍の両方が走り、上流の CLI が七本起きる。
  判定は編集器の型を使わない関数に置く（そうしないと確かめられない）。
- 指紋の状態は上流の所見から取る。このドメインは指紋を突き合わせない（SPEC-004）。
- 一つのファイルに複数の範囲が在ってよい。入れ子は上流が誤りとして挙げるので、
  こちらでは重なりを解こうとしない。返ってきた範囲をそのまま重ねる。
- 帯の色は編集器の主題の変数から取る。明るい主題と暗い主題の双方で見分けが付くようにする。
- 帯の行と種類を決めるのは編集器の型を使わない関数である。編集器の中でしか
  確かめられない形にすると、受入基準に対応する試験が置けなくなる。
- 範囲の取得が済むまで、見出しも帯も出さない。空を出してから足す形にしない。
- 利用者に見える文字列は翻訳を経る（ADR-007）。原文は英語で書き、日本語は翻訳として持つ。
  実装に日本語の表示文字列を直に書かない。`model` の層は文言ではなく符号を返し、
  訳す責任は描き手が持つ。

## エラー時挙動

| 事象 | 挙動 |
|---|---|
| 範囲が指す文書がグラフに無い | 見出しに id だけを示し、開く操作を無効にする |
| 範囲の行がファイルの行数を超える | ファイルの末尾までを範囲として重ねる |
| 命令を対応の無い場所で呼ぶ | 対応が無い旨を示して終わる |
| 実装へ跳ぶ先が複数ある | 選ばせる。選ばずに閉じたときは何もしない |
| 範囲の取得が済んでいない | 見出しも帯も出さない。取得が済んだら出す |

## 受入基準

1. 印が囲む範囲を含むファイルを開くと、範囲の始まりの行に見出しが出る。
2. 見出しの一つ目を押すと、結ばれた文書が開く。
3. 指紋が食い違っているとき、見出しに食い違いが示され、帯の色が変わる。
4. 印を含まないファイルには、見出しも帯も出ない。
5. 「この範囲の文書を開く」を範囲の外で呼ぶと、対応が無い旨が示され、例外が出ない。
6. 「この文書の実装へ跳ぶ」を範囲が二つある文書で呼ぶと、二つが選択肢として出る。
7. 指紋の突き合わせが実装のどこにも書かれていない。
8. 実装のどこにも日本語の表示文字列が無い（注釈と統治文書は対象外。全角の約物を含む）。
9. manifest が参照する翻訳の鍵が、英語と日本語の双方に在る。
10. manifest が既定のキー割り当てを持たない。

## 実装の指紋

この仕様を実装している範囲は、コード側で `doctrine:begin SPEC-005` と
`doctrine:end SPEC-005` の対に囲んである。範囲の中身が変われば指紋が変わり、
監査が `trace_stale` を警告として挙げる。実装を直したら
doctrine プラグインの `trace-index.py` で取り直す。
