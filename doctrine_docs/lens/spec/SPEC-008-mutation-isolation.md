# 潰しの隔離

`tools/mutate-check.mjs` が、潰しをどこへ当てるかの規則である。当てる先は対象の commit から
作った捨てられる木であり、利用者の作業木ではない（ADR-015）。

守る性質は一つに尽きる。**どの経路でも、作業木は一バイトも動かない。**

## 入出力

### 入力

| 何 | 出所 | 使い方 |
|---|---|---|
| 対象の指し方 | 第一引数。既定は `HEAD` | `git rev-parse` で commit へ解く |
| 作業木の状態 | `git rev-parse HEAD` と `git status --porcelain=v1 -z` | 走行の前後で一致することを確かめる |
| 既存の worktree | `git worktree list --porcelain` | 孤児の隔離木だけを見分ける |
| 束ね | 作業木の `node_modules` | 隔離木から繋いで読む（複製も再取得もしない） |

### 投影

- 隔離木の場所と、展開した commit
- 前の走行が残した孤児を片づけたときは、その場所
- 走行の終わりに、判定の履歴（SPEC-007）へ「潰した木」の一行を足す

## 隔離木

置き場所は一時ディレクトリの下で、名前は `doctrine-lens-mutate-<リポジトリの指紋>-<pid>` とする。
この形が「この道具が作った木」の唯一の見分けであり、孤児の片づけはこの形だけを対象にする。

`git worktree add --detach` で作る。detached なので、その `HEAD` がそのまま「潰した対象」である。

`.mutate-restore.json` は作らない。木ごと捨てられるので、戻し方をディスクへ残す必要が無い
（一行ごとの戻しは隔離木の中だけで行い、次の一行の baseline を保つ）。

## 排他

リポジトリ単位で錠を取る。錠はディレクトリの作成（原子的）で表し、中に走行の pid を書く。

| 状況 | どうするか |
|---|---|
| 錠が無い | 取って進む |
| 錠が在り、持ち主が生きている | **潰しの前に**失敗させる。錠の場所を報せる |
| 錠が在り、持ち主が死んでいる | 引き継ぐ（一度の強制終了で以後ずっと走れなくならない） |

## 孤児の片づけ

走り出しに、前の走行が残した隔離木を片づける。片づける条件は**三つ揃ったときだけ**とする。

1. 一時ディレクトリの下に在る
2. 名前がこの道具の形（上記）に一致し、リポジトリの指紋が同じ
3. 名前に埋めた pid が生きていない

利用者が自分で作った worktree には触らない。いま走っている自分の隔離木にも触らない。

## 制約

1. 利用者の作業木へは書かない。潰しも、戻しの記録も、報告の途中結果も書かない。
2. 利用者の dirty state を自動で clean や reset しない。汚れていたら報せるだけにする。
3. 隔離木は使い捨てとし、走行の終わりに消す。
4. 報告は隔離木を消す**前に**組む（消したあとでは `HEAD` を引けない）。
5. 未コミットの変更は、明示しない限り検査対象に入れない。暗黙に作業木を使わない。

## エラー時挙動

| 何が起きたか | どうするか | 終了符号 |
|---|---|---|
| 別の走行が錠を持っている | 潰しに入らず、錠の場所を報せる | 2 |
| 対象を commit へ解けない | 錠を解いて止める | 2 |
| 隔離木を作れない | 錠を解いて止める | 2 |
| SIGINT / SIGTERM / SIGHUP | 隔離木を消し、錠を解いて止める | 130 |
| 強制終了（SIGKILL） | その場では何もできない。**次回起動が孤児として片づける** | — |
| 走行の前後で作業木の状態が違う | 掃除せず、別の何かが触った疑いを報せる | 2 |
| 隔離木を消せない | 実体を消して `git worktree prune` に委ね、駄目なら次回起動へ残す | 走行の判定に従う |

## 受入基準

1. 隔離木が作業木の外に立ち、対象 commit の中身を持つ。
2. 隔離木を潰しても、作業木は一バイトも動かない。片づけの後も動かない。
3. 隔離木を消すと、実体も git の登録も残らない。
4. 走行が二つ重なると、後の一つが潰しの前に失敗する。
5. 死んだ走行が残した錠は引き継げる。
6. 孤児の片づけが、利用者が自分で作った worktree に触らない。
7. 孤児の片づけが、いま走っている自分の隔離木に触らない。
8. 作業木の追跡下が動けば、走行の前後の照合がそれを捉える。

## 覆わないもの

- 強制終了の**直後**に隔離木がディスクに残ること。次回起動まで一時ディレクトリを占める。
  作業木が汚れることはない。
- 合否の判定そのもの。SPEC-007 が定める。

## 実装の指紋

この仕様を実装している範囲は、コード側で `doctrine:begin SPEC-008` と
`doctrine:end SPEC-008` の対に囲んである。範囲の中身が変われば指紋が変わり、
監査が `trace_stale` を警告として挙げる。実装を直したら
doctrine プラグインの `trace-index.py` で取り直す。

| 範囲 | 何 |
|---|---|
| `tools/mutate-worktree.mjs` | 隔離木の作成・排他・孤児の片づけ・作業木の状態の指紋 |
| `tools/mutate-check.mjs` | 走行の組み立てと後始末、作業木の不変の確かめ |
