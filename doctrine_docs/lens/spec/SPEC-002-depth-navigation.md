# 深度の段と行き来

## 入出力

入力は SPEC-001 が返すグラフと、いま選んでいる深度と焦点。出力は描画する節点と辺の集合。

深度は四つの段を持つ。段の番号と意味の正本は ICD-001 にある。

| 深度 | 焦点 | 節点 | 辺 |
|---|---|---|---|
| L0 | 無し | ドメインごとに一つ | ドメインをまたぐ辺だけ。同じドメイン内の辺は畳む |
| L1 | ドメイン一つ | そのドメインの文書 | そのドメイン内の辺 |
| L2 | 文書一つ | その文書と、直接つながる文書 | その文書に接する辺だけ |
| L3 | 文書一つ | その文書に結ばれたコード範囲 | 無し |

L3 を実装する決定は ADR-005 にある（ADR-003 の「最初のスライスを L0 から L2 に限る」を置換した）。

### L3 の節点

節点は、上流の `trace-index` が返す範囲のうち、焦点の文書に結ばれたものである。
範囲の取得の仕様は SPEC-004 にある。

各節点はファイルのパス・始まりの行・終わりの行を持ち、選ぶと編集器でその行が開く。

焦点の文書に結ばれた範囲が一つも無いとき、L3 の節点は空になる。
このとき L3 へ降りる操作は効かない（節点が一つも無い段へは降りない、の一般則に従う）。

### L3 からの上がり方

一つ浅い段へ戻る。焦点の文書を保ち、その文書の L2 へ戻る。

### 降りる

L0 でドメインを選ぶと L1 へ降り、そのドメインを焦点にする。
L1 で文書を選ぶと L2 へ降り、その文書を焦点にする。
L2 で焦点そのものを選ぶと L3 へ降り、その文書に結ばれた範囲を並べる。
L2 で隣の文書を選んだときは、深度を変えず焦点をその隣へ移す。
降りる操作は全ての段で同じ一つの操作である。

### 上がる

一つ浅い段へ戻る。L1 から上がるとき焦点を捨てる。L2 から上がるとき焦点のドメインを保ち、
そのドメインの L1 へ戻る。L3 から上がるとき焦点の文書を保ち、その文書の L2 へ戻る。
L0 で上がる操作をしても何も起きない。

### 履歴

降りた順を保ち、上がる操作はその逆順にたどる。履歴は画面を閉じるまで保つ。

## 制約

- 深度を変えても、レンズの他の三つのダイヤル（色・絞り・配置）の値は変わらない。
- L0 の節点はドメインであり、文書ではない。ドメインは上流の節点が持つ `domain` の値から集める。
  このドメインが独自にドメインの一覧を持たない。
- L0 の辺は、両端のドメインが異なる辺だけを集め、同じ両端の組を一本に畳む。畳んだ本数を保つ。
- 節点が一つも無い深度へは降りない。降りる操作を無効にする。
- 配置の計算は決定的である。同じ入力からは同じ座標を出す。乱数と時刻を使わない。
- 段を戻したこと・辺を省いたことは、本体からの通知とは別の帯に出す。同じ帯を使うと、
  本体が取得のたびに送る「消せ」に巻き込まれて必ず消える。

## エラー時挙動

| 事象 | 挙動 |
|---|---|
| 焦点のドメインがグラフから消えた | L0 へ戻し、消えた旨を示す |
| 焦点の文書がグラフから消えた | そのドメインの L1 へ戻す。ドメインも消えていれば L0 へ戻す |
| L3 で範囲が一つも無い | その文書の L2 へ戻し、結ばれた範囲が無い旨を示す |
| 辺の片端がグラフに無い | その辺を描かない。落とした本数を画面に示す |
| グラフが空 | 空である旨を示す。異常として扱わない |

## 受入基準

1. L0 から降りる操作だけで L2 へ到達できる。
2. L2 から上がる操作を繰り返すと L0 へ戻る。
3. 深度を変えた前後で、色・絞り・配置の三つの値が変わらない。
4. L0 の節点の数が、グラフに現れるドメインの異なり数と一致する。
5. 同じドメインの組を結ぶ辺が複数あるとき、L0 では一本に畳まれ、畳んだ本数が保たれる。
6. 同じグラフを二度描くと、節点の座標が完全に一致する。
7. 焦点の文書をグラフから取り除くと、例外を出さずにそのドメインの L1 へ戻る。
8. コード範囲を持つ文書の L2 で焦点を選ぶと L3 へ降り、範囲が節点として並ぶ。
9. L3 から上がると、焦点の文書を保ったままその文書の L2 へ戻る。
10. コード範囲を持たない文書からは L3 へ降りられない。

## 実装の指紋

この仕様を実装している範囲は、コード側で `doctrine:begin SPEC-002` と
`doctrine:end SPEC-002` の対に囲んである。範囲の中身が変われば指紋が変わり、
監査が `trace_stale` を警告として挙げる。実装を直したら
doctrine プラグインの `trace-index.py` で取り直す。
