# 統治木を俯瞰から実装まで連続した深度で見る

## 要求文

読み手は、統治木の全体像と、ある一つの文書の細部とを、同じ一枚の画面で行き来できる。

深度を下げる操作と上げる操作は、どの段でも同じ一つの操作である。段ごとに別の操作を覚えなくてよい。

この要求が満たされたことは、次の二つで確かめる。

1. 最も浅い段から最も深い段まで、下げる操作だけで到達できる。
2. どの段からでも、上げる操作の繰り返しだけで最も浅い段へ戻れる。

## 優先度

高。この要求が満たされなければ、他の機能を載せる土台が無い。

## 受入基準参照

TEST-002

## 出所

本書 §3.3.3 が述べる「世界地図にもいろいろな種類があります」の指摘と、
C4 モデルが採る一本の倍率軸という構成。いずれも、視点を並列に増やすより一本の軸に畳むほうが
読み手が迷わないことを示す。
