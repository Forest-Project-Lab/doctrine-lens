# PR11: 起草者へ差し出す要件の口(作業の記録)

- 日付: 2026-08-15
- 位置づけ: **実験ブランチ内の作業の記録**であり、統治木の ADR ではない。
- 経緯: doctrine#294 第2信 §3-3 で当方が提案し、上流が「ありがたい。待つ。
  それまで M 層の不変条件はこちらへ写さない(ADR-165 決定6)」と応じた口。

## なぜ要るか

当方の器は**二層**である。

| 層 | 正本 | 上流が知る術 |
|---|---|---|
| 形(必須欄・語彙) | `gold-model/schema.json` | **在る**(上流が一枚を同梱して導く。ADR-165) |
| 不変条件 | 当方の検査器 | **無かった** |

上流の起草者は後者を知る術が無く、**散文の手引きを写す**しかなかった。写しは割れる ——
実測で、上流の必須欄が当方の器と食い違い、**M-18 と M-14 の両方で落ちた**(#294 第2信)。

## 口

```
node research/system-map/gold-model/validate.mjs --requirements --json
```

`system-map/requirements/1` を返す。**この口は新しい事実を一つも持たない。**

| 出す物 | 導く先 |
|---|---|
| 器の名と指紋 | `schema.json` を実際に読んで sha256 を取る |
| 文言 | `registry.json` の不変条件の `statement` |
| 見た単位・註釈 | 検査器(`check-model.mjs`)が持つ物 |
| 裏づけ | `negatives.json` の、その検査器を試す負例 |
| 政策 | `registry.json` の `policy`(値も出所も) |

**形は写さない。** `container` が指す一枚が正本であり、そちらから導けと言うだけである。

## 実測(2026-08-15)

| | 件数 |
|---|---|
| 要件(模型を判ずる検査器) | **18** |
| 除外(生成物・実ブラウザ・門そのもの) | 16 |
| **負例で裏づけた要件** | **5** |
| **裏づけの無い要件** | **13** |

**13 件は「破ると門が鳴る」ことを確かめていない。** 要件として述べているだけである。
`proven: false` として出し、`limits` にもそう書く —— 述べたことと確かめたことを混ぜない。

## 分類を正本へ足した

`checkers[].judges` を足した(`model` / `artifact` / `gate`)。`build:reachability` は
模型を判ずるが `prototype/gates.mjs` に在り、`build:no-runtime-fetch` は生成物を判ずるので、
置き場だけでは分けられなかった。**分類はどこかに要る。写しにしないため正本に一箇所だけ置く。**

`spec.mjs` が読み込みの時点で検め、分類の無い検査器が在れば止まる —— 新しい検査器を
足したその場で止まるので、要件の一覧から**黙って漏れる**ことがない。

## 門(M-Q1)が検めること

`meta:requirements-complete`(段 `registry`)。**中身の正しさではなく過不足**を見る。

1. 口が在り、`system-map/requirements/1` を返す
2. 差し出す器の指紋が実物と一致する(古い器を指していない)
3. **どの検査器も黙って消えない**(要件か、理由つきの除外か。両方は不可)
4. **模型を判ずる検査器が除外の側へ回されていない**
5. 要件が名指す不変条件が登録と一致し、文言が写しでない
6. 負例で裏づけた要件が、その検査器を試す実在の負例を指す
7. `proven` の旗が実体と一致する

## 変異の表が、当方の門の穴を見つけた

「要件から一つ落とす」潰しを足したところ、**発火しなかった**。

落とした検査器は消えるのではなく `else` の枝へ回り、**「理由つきの除外」として出ていた**。
理由が在るので検め 3 を素通りしていた。門を強くした(検め 4 を追加)。

**潰しが門より賢かった一例である。** 門を直したうえで、潰しが鳴ることを実測した(13 個の潰し)。

## この口が保証していないこと

- **意味の正しさは検めない。** その要素が本当に在るか、その流れが実際に起きるかは見ていない。
- **18 件のうち 13 件は裏づけが無い。** 負例を足すのは別の仕事である。
- **形は含まない。** 器の一枚が正本であり、この口はそれを指すだけである。
- **上流が実際にこれを引くかは当方の手の外。** 引かれるまで、割れは同じ形で起こりうる。
- この一覧が**起草に十分**であることは言っていない。覆っているのは
  「模型を判ずる検査器」であって、「良い模型」の条件ではない。
