## 作った継ぎ目

**結果を変えられない旗は作らない。** `build.mjs` と `build-overlay.mjs` は通信しないので、
そこへ `--force-offline` は置かなかった。代わりに (a) 既に在るブラウザ側の旗を**荷重に**し、
(b) 出荷する実装に通信の原始要素が無いことを静的に凍結した。

| 口 | 何のため |
|---|---|
| `--python <実行体>` | 壊れた道具の振る舞いは、壊れた道具でしか確かめられない |
| `--timeout-ms <n>` ＋ 受け皿 64 MiB | ぶら下がりと溢れを**言い分ける** |
| `--require-commit` | 版だけの一致を、完全な一致と呼ばない |
| `verify.mjs --report-dir` | 走行の後に「何を見たか」を読めるようにする |
| `test-chaos.mjs --only` | 変異の表が一件だけ回すための道具立て(掃引が狭まることを刷る) |

`pin_state` を三段に割った —— `matched` / `matched-version-only` / `commit-mismatch` / `mismatch`。
`--require-pin` の意味は変えていない(CI と手元の門はこれで回っている)。

## 決めたこと

| 決めた | なぜ |
|---|---|
| 時間切れ・溢れに**新しい状態を作らない** | 状態を増やすと画面と了解の記録が増え、増えたことを誰も検めない。`unverifiable` の理由で言う |
| 由来を辿れない木は `null` | `false` は「調べて問題が無かった」である。調べられなかったことと同じ形にしない |
| **M-14 の SKIP に了解を与えない** | 対応する判定が無い了解は `meta.acknowledgement_stale` になるので、**健全な走行のたびに赤くなる** —— 望ましくない以前に動かない。`PASS` は嘘になる(伝送が起きていないなら、その主張は試されていない) |
| `overlay.schema.json` を**作らない** | 正本が三つになる。総括の語彙・生成器の綴り・両者を突き合わせる段が在れば、離れたときに落ちる |
| 錠は待たずに止まる | 待つと、詰まった走行が「遅い走行」に見えて原因が読めない |
| 死んだ持ち主の錠は継ぐ | 継がないと、一度の強制終了で木が永久に詰まる |

## 偶発の通信失敗を、その場で観測した

一括判定の走行中に、外部への伝送が一度だけ成立しなかった。同時刻の `curl` は HTTP 200 を
返し、再走行では全件通過した —— **偶発である**。そのとき段は **SKIP(判定不能)** と言い、
FAIL(破損)とは言わなかった。走行は緑にもならなかった。
記録: `logs/OBSERVED-transport-skip-not-fail.md`。
