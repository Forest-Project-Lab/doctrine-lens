# DESIGN-001: システム画面は構成図を採る(所有者判断の記録)

- 日付: 2026-08-04
- 裁定: 所有者(issue 204 のコメント、04:33 UTC)。**これは実験ブランチ内の設計判断の記録**であり、
  統治木の ADR は Phase 1 の終了裁定(移管/検証継続/閉鎖)で起こす(台帳 v3.2-8・§5 の読み)。

## 決定(所有者の文言の要旨)

1. 構成図(旧 案B)を System Map の主画面として採用する。
2. 表(旧 案A)を独立した切替表示としては採用しない。
3. 表が持つ「接続を正確に列挙する機能」は、選択した構成要素の IN/OUT 詳細として図の側へ統合する。
4. 利用者へ表示方式の選択を要求しない。
5. A/B 比較用の実験切替は、この記録の後に UI から除去する。

判断理由(要旨): 原問題は「目的・責務・IN/OUT・保証を同じ対象上で議論できる中小粒度の表現の不在」。
表は接続の精密な確認に適するが、位置関係と全体の流れの入口として不足。図は中小粒度・接続の方向と
種類・各要素の四情報・段階ドリルダウン・旧地図の失敗の不再導入を同時に満たす。同格併存は判断の
利用者転嫁と UI・試験・保守の二重化のため不採用。

## H 層の扱い(同裁定)

`human_validation: UNASSESSED — independent participant unavailable`

模型作成に関与していない独立被験者が現状確保できないため、H 層は PASS としない。ただし H 層未実施を
理由に可逆的な開発は止めない(設計判断は所有者判断・AI 俯瞰レビュー・M 層検査・固定静止画・反証試験に
基づく)。実際の利用者が現れた時点で、最初の利用観察を H 層評価として記録する。

## 実装(この記録と同じ変更で実施)

- A/B 切替の除去。構成図を唯一のシステム画面に。
- 接続表を詳細パネルの「接続(IN/OUT の詳細)」へ移設 — **図と同じ Flow 正本から生成**(二重定義なし)。
- M-13/M-14 の判定器を `gates.mjs` へ切り出し、**負の試験**(`test-gates.mjs`)が発火を確認する
  (発火が確認されていない門を緑と呼ばない)。
- H 層評価一式(h-layer-protocol.md)の A/B 比較部(T8・ab-summary)は、採用判断済みのため
  「表示形式の比較」から「構成図の理解検証」へ役目が変わる — 手順書の改訂は次の版で行い、
  それまで T8 は実施しない。
