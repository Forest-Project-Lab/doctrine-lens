## 抽出器が自分を疑った話

`display-static` の走査は、最初「到達の状態」を 3 語しか採れずに **ERROR で止まった**
(下線を字の集合へ入れ忘れ、`not_applicable` を落としていた)。件数の下限を置いて
FAIL ではなく ERROR にしていたので気付けた —— **採れなかった回を、合っていた回に
化けさせない**。3 語のまま「一致」と読んでいたら、欠落は緑の中に埋まっていた。

## 決めたこと

| 決めた | なぜ |
|---|---|
| 表示の語を `policy.display` へ。読み込み時に全単射 | 足りないのも余っているのも「表と語彙が別々に動いている」印である |
| 描画は全域関数。未知の語は `unknown_token` へ落とし、**語をそのまま出す** | 画面は生成器の将来の語彙を数えられない。数えられないことを、数えたふりで隠さない |
| 画面は判定器の出力を写す。**判定をやり直さない** | 二重実装は必ず片方が緩む。実際、画面は門が認めない種別をリンクにしていた |
| 判定の行は id と判定と理由だけ持つ | 中身を写すと同じ事実が二箇所になる。実際、写した版では上流の走査が生成物の中に印らしい綴りを一つ余計に数えた |
| 帯をデータから作る | 字で書くと、一件が確認済になった日に帯だけが嘘になる |
| **確認済だけを写した正本表示は作らない** | 一度も動かない投影を作ることは、それ自体が未検証の主張になる。代わりに検査画面で「まだ一度も検められていない」と明示する |
| 何も `confirmed` へ昇格させない | M-07b は確認済が一件でも現れた瞬間に FAIL する(投影が無いため)。昇格は所有者判断でもある |
| 架空の対象は出荷を続け、**画面が架空と言う** | 役割を外すと `shoot.mjs` と H 層 T6 が成果物から消える。出荷の是非は所有者判断として残す |
| 了解の記録を画面に出す | `verify.mjs` は console に出していたが、画面の利用者は緑の意味を読めなかった |

## この緑が保証していないこと

- **了解の記録 18 件については何も検めていない。** 2026-11-09 に一斉に期限切れ。
- **M-07b はまだ一度も検められていない。** 確認済の実体が無く、確認済だけを写した
  正本表示も実装していない。画面はこの欠落を**明示するようになった**が、欠落は残る。
- **`display-static` は字面の走査である。** 生成器の綴りから語を採る規則は狭く、
  綴り方を変えれば採れなくなる(下限と ERROR がその番人だが、番人も字面である)。
- **出荷する `index.html` は overlay を同梱しない。** 実測の表示は
  `--overlay-dir` を渡した変種でしか出ない。静止画にもそう明記した。
- **H 層は `UNASSESSED`。** 語で分けたことが読み手に伝わるかは、機械では答えられない。
  `human_validation: UNASSESSED — independent participant unavailable`
- **架空の対象は依然 VSIX に出荷される。** 画面が架空と言うようになっただけで、
  捏造データが配布物に入る事実は変わっていない —— 所有者判断として #212 へ上げる。
- 色以外でも分けたが、**色覚・単色印刷での実地確認はしていない**(語が在ることを
  機械で確かめただけである)。
